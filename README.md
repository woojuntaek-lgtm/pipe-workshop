# 파이프라인 공방

동전 던지기를 87%로 맞혔다? — 파이썬으로 처음부터 끝까지 이어지는 데이터 분석 프로젝트를 손으로 체험하는 앱입니다. 패턴이 하나도 없는 난수 데이터(표본 100 × 열 최대 10,000)에서 열 고르기를 전체 데이터로 하면 정확도가 높게 나오고, 교차 검증의 학습 구간 안에서 하면 동전 던지기 수준으로 떨어지는 데이터 누수를 브라우저에서 직접 계산해 보여 줍니다. 우연히 1등이 된 열 보기, CRISP-DM 여섯 단계, 첫 탐색 다섯 줄(pandas 3.0 실제 출력), 퀴즈 ①(interpolate → 12, 14), 하루 주기 온도의 긴 공백 함정(2칸 0.14 °C, 20칸 9.16 °C)과 limit, rolling·diff·get_dummies 특성 만들기, 파이프라인 안팎에서 fit이 보는 곳, 시드 고정과 재현성, 흐름을 함수로 묶기, base64로 그림을 넣는 HTML 보고서와 퀴즈 ②(약 400KB)까지 담았습니다. 파이썬 13 부록이며, 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

## 구성
- ① 87%의 비밀: 누수 실험, 우연히 잘 맞아 보이는 열
- ② 흐름·탐색: CRISP-DM, 첫 탐색 다섯 줄
- ③ 빈칸·특성: 퀴즈 ①, 긴 공백의 함정, 특성 만들기
- ④ 재현·보고서: 파이프라인, 시드, 함수로 묶기, 보고서 자동화, 퀴즈 ②, 세 줄 정리, 생각해 볼 질문

누수 실험은 앱 안의 난수로 만든 데이터로 ANOVA F 점수 열 고르기와 로지스틱 회귀(사이킷런 기본값과 같은 L2, C = 1)를 브라우저에서 직접 계산합니다. 폴드 나누는 방식이 사이킷런과 조금 달라, 원고 메모의 numpy 데이터에 적용하면 84% / 49%가 나옵니다(사이킷런은 87% / 47%). 첫 탐색의 센서 기록 8행, 특성 만들기의 상태 열은 설명용 가상 데이터입니다. 온도 곡선은 원고 메모의 식을 그대로 썼습니다. 다섯 줄 출력은 pandas 3.0.5로 실제 실행한 결과입니다.
